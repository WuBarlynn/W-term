# Cloud Term 功能对照审计（2026-10-30）

来源：https://www.cloudterm.cn/guide.html（公开页面，2026-10-30 抓取）。范围包含连接管理、终端、文件、片段、同步、组织协作、桌面端和云服务；**按用户要求排除自定义皮肤和彩蛋小游戏**。本文件是开发对照表，不把“已规划”当成“已实现”。

状态：`[x]` 已有可用实现；`[~]` 部分实现或有明确边界；`[ ]` 尚未实现。
