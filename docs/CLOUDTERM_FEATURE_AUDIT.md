# Cloud Term 功能对照审计（2026-10-31）

来源：https://www.cloudterm.cn/guide.html（公开页面，2026-10-30 抓取）。范围包含连接管理、终端、文件、片段、同步、组织协作、桌面端和云服务；**按用户要求排除自定义皮肤和彩蛋小游戏**。本文件是开发对照表，不把“已规划”当成“已实现”。

状态：`[x]` 已有可用实现；`[~]` 部分实现或有明确边界；`[ ]` 尚未实现。

## 验收边界

本表只说明代码能力；真实 Apple 设备、Windows 桌面输入、真实 GitHub 双设备、真实 OpenSSH/代理/转发、弱网和四周日用仍需单独验收。当前 **1.0.52（105）** 构建有三端安装包、签名/版本核验和 320 项 Flutter 测试（含真实 lrzsz ZMODEM 双向测试），但仍不能称为 Cloud Term 全功能等价。
