# Cloud Term 功能对照审计（2026-10-30）

来源：https://www.cloudterm.cn/guide.html（公开页面，2026-10-30 抓取）。范围包含连接管理、终端、文件、片段、同步、组织协作、桌面端和云服务；**按用户要求排除自定义皮肤和彩蛋小游戏**。本文件是开发对照表，不把“已规划”当成“已实现”。

状态：`[x]` 已有可用实现；`[~]` 部分实现或有明确边界；`[ ]` 尚未实现。

- [x] SSH 直连、多级跳板（逐跳指纹/MFA/取消/整链清理）
- [x] 命名 HTTP CONNECT/SOCKS5 代理、主机继承/指定/直连
- [x] 密码、加密私钥、私钥口令、键盘交互/MFA、持久纯交互式身份
- [ ] SSH 证书认证
- [x] 文件夹、多选/搜索、标签、收藏、主机备注/启动配置（基础）
- [x] 服务器 Wiki（每主机 Markdown 文本，随主机保存）
- [ ] 连接图标/在线图标搜索
- [~] 临时终端（快速连接表单；无独立“临时终端”入口）
