## 已实现功能全集（2026-11-01 补充）

本清单按产品模块列出代码与界面中已经存在的能力，包含 Cloud Term 对照表之外的 W Term 自有功能。标注“边界”的项目仍可使用，但存在平台、外部服务或验收限制；不代表已完成真机日用验收。

### 连接、认证与网络

- SSH 直连；多级跳板链，跳板本身还可继续配置跳板，逐跳核对 SHA256 指纹、逐跳 MFA，支持取消连接与整链资源清理。
- 主机指纹在认证前确认；首次连接展示可信上下文，指纹变化默认阻断；已信任服务器保存在本机钥匙串，可在设置中查看并忘记。
- 认证方式：保存密码、加密私钥、私钥口令、键盘交互/MFA；交互式认证答案仅用于本次连接，不保存、不继承。
- SSH 证书：支持把 OpenSSH 用户证书与私钥一起导入，并通过 russh 证书认证登录（边界：未做真实 CA/服务器互操作验收）。
- 命名代理：HTTP CONNECT 与 SOCKS5，可保存多个代理配置与账号密码；支持默认代理、主机继承、指定代理或强制直连；草稿、已保存配置与默认代理均可测试连通性，探测可经代理完成，删除仍被主机引用的代理会被阻止。
- 端口转发：本地 `-L`、远程 `-R`、动态 SOCKS5 `-D`；可配置监听地址、端口（0 为自动分配）、目标地址/端口；对外监听需要二次确认；规则可按主机保存、搜索、编辑、启动、停止、删除与刷新，并显示当前运行状态。
- 每台主机可设置启动命令和 `KEY=VALUE` 环境变量；连接时优先通过 SSH `env` 静默注入，服务器拒绝时回退到 shell 导出，支持注释与格式校验。
- 启动命令、环境变量只作用于交互式终端，不影响 SFTP、状态采集与跳板链路。
- 身份标识管理：密码、私钥、仅交互式身份；支持生成 Ed25519 密钥、导入私钥文件、查看/复制公钥、导出带独立口令的加密私钥、附加/移除 SSH 证书；仍被主机使用的身份不能删除，同一身份可供多台主机复用。
- 导入：CSV/TSV（含密码列）、Excel `.xlsx`、PuTTY `.reg`、SecureCRT/MobaXterm `.ini`、Xshell `.xsh/.xts`、OpenSSH 配置；导入前可选择会话、文件夹结构和是否导入密码。
- 临时终端/快速连接：不写入主机库的一次性连接；设置页与深链接也可直接进入连接表单。
- `wterm://connect` 深链接支持从系统直接发起保存主机连接。

### 主机与侧边栏

- 主机新增、编辑、删除、搜索、收藏；字段包含地址/端口、用户名、认证方式、身份、代理、跳板链、文件夹、标签、连接图标、备注、启动命令与环境变量。
- 主机图标支持内置图标和 Iconify 在线搜索；文件夹使用同一套图标来源，支持自定义文件夹图标。
- 多级文件夹；文件夹可重命名、删除（删除时可选择如何处理主机），可拖拽移动到其他文件夹，移动时同步迁移主机归属、子文件夹、折叠状态与文件夹图标；同名或移动到自身/子文件夹会被拒绝。
- 主机标签自动创建，支持按标签筛选和关键字搜索；服务器 Wiki 为每台主机保存独立 Markdown 文本。
- 侧边栏支持 Shift 区间多选、Ctrl/Cmd 单选增减，批量连接、收藏与删除。
- 收藏主机显示在顶部收藏栏，支持 macOS `Cmd+1~9` 与 Windows `Ctrl+Shift+1~9` 快捷打开。
- 侧边栏可拖拽调宽，可折叠为窄轨；折叠后仍保留新建、设置与关键入口。
- 临时终端、本地终端、设置与 GitHub 同步可从侧边栏/托盘快速进入。

### 终端与工作区

- 多标签：新建、关闭、重命名、拖拽排序、关闭隔离；关闭一个标签不会断开其他标签中的会话。
- 标签右键菜单：关闭左侧/右侧/其他/已断开标签、定位当前连接等。
- 分屏：把标签拖到终端边缘创建分屏，支持嵌套分屏、左右/上下双分屏、四宫格；窗格标题可拖动重排，分隔条可拖动缩放、双击复位，支持拆回标签、拆分全部窗格、关闭单个窗格。
- 聚焦模式可隐藏侧栏与文件面板；弹出窗口支持 SSH 输出交接与收回（边界：Windows/iPad 真机验收未完成）。
- 会话/视图分离：窗格重建、分屏或移动不会重建 SSH 会话；断线后可原位重连，布局可在无凭据时恢复，macOS 关窗保活。
- 广播输入：底部撰写栏可把输入发送到当前终端或全部已连接会话；广播前确认，已断开会话自动剔除，窗格重建不影响输入路由。
- 终端搜索：搜索历史快照、区分大小写、刷新快照与匹配计数。
- 复制/粘贴：选中即复制可开关、右键粘贴可开关、多行粘贴确认与编辑、全选复制。
- 划词快捷菜单：选中文本自动显示复制、固定、存为片段、分享图片；JSON/IP 入口按选区动态出现；可整体关闭或分别裁剪按钮，定位避开屏幕边缘，失焦、切换标签、右键菜单或断线时收起。
- 右键菜单：复制、全选复制、粘贴、打开文件面板、固定、存为片段、快速分享图片、模板分享、预览文件、打开链接、JSON/IP 操作与插件设置。
- 终端链接：http/https 自动下划线（可关）、选中链接打开、Cmd/Ctrl+点击打开；路径悬停下划线、Cmd/Ctrl+点击预览，支持引号包裹的含空格路径。
- 关键字高亮：最多 20 组全局关键字或按主机标签匹配的正则规则，颜色可设，随 GitHub 设置同步。
- 顶部实时状态栏：约每 10 秒显示 SSH 延迟、CPU、内存；宽窗口追加负载与根分区磁盘占用，并可显示会话信息与机器信息行。
- 系统监控：5 分钟延迟折线与最低/最高值；CPU 总/分核、内存、磁盘、负载、运行时间、主机名与内核；Linux 网卡上下行；进程搜索/排序/结束/复制 PID；端口按监听地址、协议、回环过滤；Docker 容器列表、停止与重启。
- tmux：列出、新建、进入、分离、重命名、结束会话，约 5 秒状态同步，支持批量结束。
- 终端 AI 助手：保存多个 OpenAI 兼容环境（接口地址、模型、API Key、提示词）；可调附带终端行数、命令超时与三档权限（每次询问/只读自动批准/完全访问）；支持流式输出、只读工具调用，结果可发送到终端输入或通过独立通道执行。
- 分享为图片：快速终端截图 PNG；模板分享支持终端窗口/渐变卡片/极简纯色、深色/浅色、行号、水印、自定义标题、保存、系统分享、复制图片到剪贴板与导出完整文本。
- 本地终端：桌面 PTY，macOS 使用登录 Shell，Windows 使用 `COMSPEC`（默认 `cmd.exe`）；支持独立标签、本地快捷键与终端内交互。
- 快捷键：打开连接选择器、本地终端、搜索、清空、文件面板、片段、历史、设置、关闭标签、前后标签、字号放大/缩小/重置；可录制、禁用与恢复，收藏数字与字号保留默认绑定；快捷键页附 GNU Readline 速查。
- 输入法：macOS 聚焦终端自动切 ASCII、离开恢复；Windows 提供硬件键盘输入兼容模式并默认启用（边界：Windows 真机输入法验收未完成）。
- 终端信息：会话信息显示用户名、主机、连接时长；机器信息读取远端系统、内核与主机名；均可在工作区偏好中开关。

### 文件与传输

- SFTP 面板与终端并排显示；面板可拖拽调宽，也可收起为窄轨；窄轨保留显示文件、上传与刷新按钮。
- 路径编辑、上级目录、前进/后退目录历史、刷新；同一面板复用 SFTP 连接，切换目录不重复握手；跟随终端目录后可随 OSC 7 自动切换。
- 文件名搜索、显示/隐藏点文件、按名称/大小/修改时间排序、升降序切换、多选与全选。
- 新建文件夹、重命名、删除、下载、编辑文本、修改八进制权限；权限编辑保留已设置的特殊权限位，不递归修改目录内容。
- 远程文本编辑器支持源码/预览切换、保存，并保留原文件 CRLF 换行。
- 文件预览：文本、Markdown、图片、PDF 内嵌；图片支持缩放、旋转、保存/分享；Office（docx/xlsx/pptx）抽取文本/表格并可用系统应用打开原版；媒体、Office、PDF 可通过系统应用或系统分享打开。
- 预览上限：图片 50 MB、Office 50 MB、PDF 100 MB；超出后提示先下载到本地。
- 上传文件；文件夹上传支持桌面拖拽，macOS/iOS 另提供文件夹选择器。文件夹上传前完整扫描，限制 2000 项/32 层；拒绝符号链接与特殊文件；预览中可排除隐藏项、修改目标文件夹名称。
- 上传冲突：覆盖替换、保留两个文件自动加序号、跳过服务器已有项目，并可对本批后续冲突复用选择；失败重试会重新确认冲突。
- 上传队列：逐项状态、字节级进度与百分比、搜索/筛选、取消剩余任务、失败项重试；队列跨标签保留，失败项可在同一主机的其他会话重试；队列在仍有失败项时保留源文件与 Apple 安全作用域，下一批上传或全部成功后释放。
- 下载：单个下载、多选下载、目录递归下载；本地自动安全改名并避免覆盖；跳过符号链接与危险路径；单目录最多 10000 个文件；显示进度与结果，iOS 支持文件分享。
- 下载队列/最近下载：跨标签查看下载批次、取消剩余、查看最近一次下载结果。
- 拖拽上传：桌面拖入文件/文件夹上传；可关闭拖拽上传；单文件大小上限可配置；Apple 拖入文件夹申请安全作用域，文件拖入使用 bookmark。
- 终端目录跟随：支持 bash/zsh/fish 的 OSC 7 上报；终端菜单可注入当前会话的目录上报命令，OSC 9 自动探测当前 Shell，探测失败时提示手动选择；支持停止跟随。
- ZMODEM：`rz`/`sz` 传输入口，本地修补 zmodem 帧处理并通过串行 mux 接入；真实 lrzsz 双向二进制集成测试通过。

### 片段、命令与效率

- 本地代码片段：新增、编辑、删除、搜索、复制、发送确认；字段包含名称、描述、命令、标签。
- 片段可关联主机标签或具体连接：仅当前主机具备对应标签或在绑定连接上显示；片段编辑支持标签筛选。
- 内置 128 条分类精选命令，覆盖系统诊断、网络、容器等；在线片段市场支持刷新、缓存、校验与一键入库。
- 固定命令：从终端选中命令后固定，可命名并选择“仅当前主机/全局/主机标签”范围；底部命令条与宽屏右侧 Dock 均支持发送与取消固定，长按可移出。
- 片段/固定命令随 GitHub 加密设置同步；片段发送前可确认，固定 chip 单击发送。
- 命令历史：本地最多保留 500 条；支持命令/主机/用户搜索、主机筛选、今天/近 7 天/近 30 天/自定义日期范围、复制、清空；显示时间、用户@主机。
- 命令补全插件：内置 git、docker、docker compose、kubectl、systemctl、journalctl、apt、dnf、brew、npm、pnpm、yarn、cargo、pip、go、ssh、scp、rsync、tar、tmux、curl、ps、kill、find、chmod、systemd-analyze 等命令表；终端底部提示，Tab 采纳、方向键选择、Esc 关闭，全屏程序时抑制。
- 任务完成通知：长命令空闲启发式与 OSC 133;D 精确完成标记；阈值 3–3600 秒；排除编辑器、分页器、常驻/交互式命令、`-f` 跟随命令与后台命令；应用后台走系统通知，前台失焦显示应用内通知，点击定位终端；可显示退出码。

### 插件

- 插件设置独立入口：命令补全、文件预览、IP 归属查询、JSON 格式化、任务完成通知、划词快捷菜单；插件开关随 GitHub 加密设置同步。
- IP 归属查询：选中 IPv4 查询国家/地区、省/州、城市、运营商、组织、ASN、时区、经纬度；局域网/回环/链路本地/CGNAT/保留地址本地判定，不联网；本机 24 小时磁盘缓存（最多 256 条），接口失败回退过期缓存并标注来源。
- JSON 格式化：按选区识别合法 JSON 对象/数组，弹窗显示缩进结果，可复制格式化文本或单行压缩结果；非 JSON 不显示入口。
- 文件预览：终端路径悬停与右键预览复用文本/图片/Office/PDF/媒体预览器；文件面板的 50 MB 图片/Office 与 100 MB PDF 上限不在终端路径预览前预检；SVG/AVIF 未内嵌（边界）。
- 划词菜单：IP/JSON 入口依赖选区内容；插件关闭后对应入口消失。

### 外观与字体

- 界面主题：深色、浅色、跟随系统；终端配色与界面主题可分离。
- 终端主题：多套内置配色；可复制内置主题为自定义主题，编辑背景/前景/光标/选区与 16 色；界面色调可跟随终端。
- 主题预设：深色、浅色、浅色界面+深色终端；手动切换预设会退出皮肤。
- 皮肤：8 套内置矢量背景皮肤（明暗、界面配色、终端主题联动、半透明毛玻璃）；自定义皮肤支持背景图压缩、界面底色、主色、0–60% 色罩、自动玻璃或指定终端主题、实时预览、编辑、删除。
- 自定义皮肤限制：单图 ≤2 MiB、最多 8 款、背景总量 ≤6 MiB，随 GitHub 加密设置同步。
- 字体：界面字体、终端字体、CJK 回退分别设置；内置 JetBrains Mono、Noto Sans SC；枚举系统字体；支持本地字体文件与 http/https URL 导入（≤32 MB，本机存储）；在线 SIL OFL 字体市场可下载安装；终端字体默认 Menlo。
- 终端外观：字号、行高、字重、光标样式（方块/竖线/下划线）、光标闪烁、底部留白、回滚行数（1k–50k）、选中即复制。
- Windows 界面使用 Microsoft YaHei UI/微软雅黑回退，终端使用 Menlo 等宽回退链；macOS 使用透明圆角图标，Windows ICO 使用不透明边缘，避免桌面白边。

### 保险库、备份与同步

- SQLCipher 加密保险库保存主机、文件夹、身份、片段、代理、转发规则、同步配置等本机数据；主密码解锁，支持修改主密码。
- 快速解锁：Touch ID / Face ID / Windows Hello；启用时先验证生物识别，再把主密码写入系统安全存储；可在解锁页手动生物识别或输入主密码。
- 启动自动解锁开关（设备本机保存）；关闭后启动只显示解锁页，不自动弹生物识别。
- 手动锁定保险库；iPad 多窗口共享内存中的已解锁令牌，最后一个窗口关闭时锁定；解锁后隐私遮罩立即移除。
- 身份凭证与私钥加密保存，界面只显示占位符；私钥可导出为带独立口令的 OpenSSH 格式。
- 手动加密备份导出/恢复；恢复会添加新的主机与身份并保留当前数据。
- 自动备份：每日最多一次、保留 5 份，使用系统安全存储中的本机密钥加密；可在设置中立即备份、列出、恢复。
- GitHub 私有仓库端到端加密同步：校验私有仓库、Token 权限、分支与文件路径；连接、文件夹、身份、片段、收藏、应用设置分范围同步。
- 应用设置同步内容：终端外观、插件、固定命令、关键字高亮、快捷键、文件夹图标、自定义皮肤、AI 环境/API Token。
- 同步历史：最近 30 个版本查看与恢复；恢复以新提交写入，不强制推送；三方合并与删除墓碑由核心处理。
- 冲突审阅：检测冲突后暂停自动同步，展示差异并让用户逐项选择；冲突提醒显示在顶栏。
- 同步密钥：创建、恢复码确认、密钥轮换、采用已有密钥；同步密钥只保存在本机。
- 自动同步：可开启，约每 15 分钟一次；有活动终端会话时不强行刷新，提示待手动同步。
- 断开同步：预览影响、要求备份确认与确认短语；失败时保持原绑定，不删除远端历史。
- 设备安全设置、自动解锁偏好、命令历史与同步密钥保持本机，不进入同步快照。

### 桌面端、移动端与发布
