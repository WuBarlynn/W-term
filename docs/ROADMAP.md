# 当前开发路线

更新：2026-10-30。本文件是后续工作的执行顺序；完整功能来源、当前差距、平台边界和验收要求见 [Cloud Term 对标计划](CLOUDTERM_PLAN.md)。[原计划](../PLAN.md)保留历史目标，发生顺序或范围冲突时以本文件及用户最新要求为准。技术路线保持 Flutter 自适应界面 + Rust 共享核心。

当前应用为 **1.0.14+67** 三端开发预览。已完成连接闭环、P1.5-A/B/D/E/F、macOS 关窗保活与 Windows Release 构建；独立弹出窗口仍受单 Flutter 引擎架构限制，P2 真机/四周日用验收未完成，不能视为最终验收版。

## 范围与取舍

- 继续以Cloud Term非彩蛋产品能力为长期对标方向，按价值、依赖与平台限制分批实现。2026-10-24复核8个公开内容页、24个日志章节、3个匿名资源目录及发布清单，保留旧编号并补至C001–C203共203条跟踪项；S3仍是对方规划中项目。日志HTML停在0.3.3，发布清单已为0.3.5（2026-10-23），不能只看旧日志判断能力。访问失败、素材许可和来源冲突见对标计划。
- 不只做SSH：正式纳入工作区/分屏/广播/多窗口、监控/Docker/tmux、Redis/Telnet/串口/外部RDP、AI、内置插件、更多同步后端、账号组织和Web。不是照搬对方技术栈或商业服务。
- 先完成macOS和iOS/iPadOS核心并验收，再进入Windows；高级能力按下面阶段交付，Web独立设计，Android仍最后评估。桌面本地Shell、托盘、串口等不承诺移动端机械等价。
- **SFTP新功能仍暂停**：P1–P4只修影响使用/数据安全的缺陷。P5保留队列、续传、递归下载等候选需求，但开工前必须由用户明确解除暂停；未解除则跳过该线，不自动恢复扩展。
- 已有MFA、全局连接代理、手动GitHub E2EE/恢复码/轮换及丰富的轻量SFTP，不从零重做。当前同步仅Host/Identity/Snippet/Folders，不是所有设置；终端/SFTP并排不是多终端分屏；SOCKS5连接代理不是动态转发。
- 自动化、构建、签名、真实环境验收分开。不得为对标关闭指纹阻断、代理失败直连、重放命令、强推或删除未知发布结果；对危险默认行为提供安全等效流程。

### 已完成：P1-A 多级跳板（0.1.44）

1. 主机模型新增 `jumpHostIds`，保存时校验长度、自引用、重复、缺失、循环和最多 4 台跳板；删除依赖、备份恢复重映射、同步悬空引用与仅本机依赖闭包均已接入。
2. 第一跳沿用全局代理，后续跳只通过上一跳的 `direct-tcpip` 通道；通道拒绝或上游断开时不会回退直连。
3. 每跳独立显示目标、确认指纹并认证/MFA；第一跳沿用 `host:port` 信任键，后续跳使用路线作用域的信任键，直连旧信任不会自动推广到内网目标。
4. 探测有操作标识，可在握手阶段即时取消；每个连接记录父链，取消、超时、断开任一跳、锁库、iOS 后台与工作区销毁都会清理整条链。
5. 已用双 SSH fixture、真实 Dart/Rust 桥接和两端构建核验；真实 OpenSSH 多跳/PAM/TOTP、弱网与签名真机仍待验收。

### 已完成：P1-C 远程/动态转发与规则（0.1.46，2026-10-28）

1. 会话“端口转发”统一支持本地 -L、远程 -R、动态 SOCKS5 -D；默认回环，非回环必须勾选确认，启动已保存的非回环规则会再次确认。
2. 远程 -R 通过服务器的 `tcpip-forward` 建立监听，服务器的 `forwarded-tcpip` 通道由客户端连接本机目标；停止时取消服务器监听并中止活动中继。
3. 动态 -D 在本机提供无认证 SOCKS5（仅 CONNECT/TCP），每个客户端自选目标，经当前 SSH 传输转发。
4. 规则按主机保存在本机 SQLCipher（不同步、不随业务恢复），支持名称、搜索、编辑、删除和手动启停；保存不自动启动。每会话最多 8 条活动转发、每条 32 并发，目标连接 15 秒超时。
5. 验证：端口冲突、远端拒绝、停止释放、断开会话清理、动态握手/目标拒绝、真实桥接与双端构建见 [STATUS.md](STATUS.md)。真实 OpenSSH、签名真机、弱网与压力仍待验收。

### 已完成：P1-B 认证与代理（0.1.45，2026-10-28）

1. 身份新增 `interactive` 类型：只保存名称/用户名，不保存密码、私钥或口令；每次连接（含跳板）由服务器在打开终端前询问，回答不落库、不同步、不重放。旧式临时留空密码连接保留。
2. 命名 HTTP CONNECT/SOCKS5 代理保存在本机 SQLCipher，读取只返回“密码已保存”；端点/用户名变化必须重新输入，密码不回填。默认代理保留为“继承”目标，旧全局设置无需迁移即成为默认。
3. 主机代理选择为设备本地绑定：继承默认、直连或指定命名代理。指定代理在本机不存在时拒绝连接，不回退默认或直连。删除仍被主机使用的代理会被阻止；删除主机/同步变化后会自动清理失效绑定。
4. 分层连通测试区分代理 TCP 可达、代理认证通过、目标 TCP 可达；支持默认代理、指定代理、草稿和全部代理顺序测试，目标可留空仅测 TCP。
5. 真实验证：单测/桥接覆盖密码复用、主机绑定、显式直连覆盖默认、删除依赖、错误密码与目标失败分层、持久交互式身份重开后再认证；真实代理产品、真实 OpenSSH 多跳与签名真机仍待验收。

### 已修复与效率调整（0.1.48，2026-10-30）

- 关闭一个标签只移除该标签的窗格视图并断开其自己的会话；先移除视图/标签，再逐会话关闭，其他标签不受重建或生命周期影响。确认框列出将断开的用户名@主机；后端新增“关闭两会话之一，另一终端仍可输出”的 fixture 回归。
- 左侧主机栏可拖动分隔条调宽（200–480），可收起为窄栏；窄栏保留展开、新建连接、设置与锁定按钮。左下角设置项收进“设置与工具”折叠菜单，不再占用半屏高度。
- 右侧 SFTP 面板可拖动调宽（240–560）；收起后保留显示文件、上传、刷新文件列表三个小按钮，终端获得更多空间。
- 启动时若已启用 Touch ID/Face ID，自动弹出系统生物识别解锁；用户取消后不循环重试，锁屏保持主密码入口。
- iOS 隐私遮罩：锁屏本身不再叠加遮罩，生物识别系统弹窗期间不触发遮罩；成功解锁立即清除遮罩和 hidden 状态，resumed 也会统一清除，修复解锁后残留 1–2 秒。
- 验证：Flutter 全量回归、生物识别/遮罩/侧栏测试、Rust 独立会话 fixture、双端构建；真实 iOS 后台/生物识别残留需用户在签名真机复核。

### 已完成：P1.5-A/B 会话/视图分离与分屏（0.1.47，2026-10-28）

1. 新增 `TerminalSession`：xterm 模型、输出订阅/ACK、输入队列、resize 和结束状态由会话持有；`TerminalPane` 只是可移动视图，切换/移动不重连、不丢缓冲。
2. 标签支持拖动排序、双击/长按重命名、关闭；关闭标签断开其中全部会话。每个标签拥有独立窗格树。
3. 窗格支持水平/垂直/嵌套分屏、分隔条比例、焦点切换、拆回标签、关闭窗格；分屏时从其他已打开会话选择并移动，不复制终端。
4. 标签栏分屏手柄可拖到窗格四边，带落点高亮，合并整个标签树。
5. 布局模型单测、全量 Flutter 回归和双端构建见 [STATUS.md](STATUS.md)。**未在模拟器/真机实际操作连接后的拖动、分屏和拖拽落点**；P1.5-C（弹窗窗口/保活收回）、D（广播）、E（查找/快捷键）、F（重连/布局恢复）仍未实现。

### 下一轮可直接执行：P1.5-C/D 弹窗、保活与广播

1. 弹出/拖出标签或窗格到独立窗口；同一 `TerminalSession` 由明确 owner 管理，目标确认接管后再移除原视图，失败可回退。
2. 收回主窗/指定组；关闭子窗明确“收回”或“断开”，主窗退出/锁库统一清理，不泄漏凭证。
3. 广播输入默认关闭：明确选择当前/组/指定/全部目标，持续显示接收者；撰写栏预览、暂停/退出，IME/Ctrl+C 语义正确；断线/关闭目标实时剔除。
4. 跨窗口广播不重复发送；目标确认与视图迁移的 ACK 完成后再移除旧视图。
5. C/D 完成后补 E（基础快捷键/每窗格查找/选择器）与 F（手动重连/描述性布局保存恢复），再做 P2 真机验收。

## 已有交付与待验收记录

### 已交付：P1-B 认证与代理（0.1.45，2026-10-28）

- 身份支持“仅交互式”：不保存密码/私钥，每次连接由服务器询问；跳板与目标都可使用。回答不落库、不同步、不重放。
- 本机命名 HTTP CONNECT/SOCKS5 代理：名称、端点、可选用户名密码；读取不回显密码，修改端点/用户名后必须重输。删除仍被主机使用的代理会被阻止。
- 主机级代理绑定：继承默认、直连、指定命名代理。指定的代理在此设备缺失时拒绝连接，不回退默认或直连；代理只作用于第一跳。
- 分层连通测试：分别显示代理 TCP、代理认证、目标 TCP 三段结果；支持默认、命名、草稿与全部代理测试，目标可留空仅测 TCP。
- 验证：Rust 单测覆盖密码复用、绑定/删除依赖、显式直连优先、错误密码与目标失败分层；忽略 fixture 覆盖持久交互式身份重开后再认证；真实桥接覆盖主机绑定、显式直连失败、分层测试和持久交互式身份。真实代理产品、真实 OpenSSH 多跳与签名真机仍待验收。

### 已交付：多级跳板 P1-A（0.1.44，2026-10-28）

- 主机编辑器可添加、排序、移除跳板主机；连接时按顺序逐跳显示进度，每跳独立确认指纹并支持 MFA；跳板只认证、不打开终端。
- 第一跳沿用本机 HTTP CONNECT/SOCKS5 代理，后续跳通过上一跳 `direct-tcpip` 通道；失败不回退直连。第一跳沿用原 `host:port` 信任键，后续跳使用路线作用域键，避免把直连信任自动推广到内网目标。

### 已交付原型：本地转发边界（历史，已由 P1-C 扩展）

> 以下为 0.1.25 的本地 -L 原型记录；0.1.46 已加入远程 -R、动态 -D 和保存规则，规则/监听边界以 [SSH_FORWARDING.md](SSH_FORWARDING.md) 为准。

连接已认证主机 → 会话顶部“端口转发” → 填写目标及本地端口 → 启动 → 通过本机地址访问 → 停止或断开会话。

- 首版只绑定 `127.0.0.1`；本地端口 `0` 表示自动分配，目标端口必须为 1–65535。
- 目标地址从 SSH 服务器侧连接；监听成功并不证明目标服务可访问，连接失败在刷新列表后显示。
- 每会话最多 8 条转发，每条最多 32 个并发连接；目标通道连接超时 15 秒。
- 转发与当前会话绑定。关闭管理窗口继续转发；停止、终端退出、会话断开会释放资源。当前 iOS 后台策略会断开 SSH，因此同时停止转发。
- 本轮不保存转发规则、不自动恢复、不绑定局域网地址；远程转发和动态 SOCKS 位于阶段 3。
- 真机后台/前台、真实 OpenSSH 服务器、macOS 沙盒和长连接压力测试仍需验收。
