# SSH 连接代理

更新：2026-10-28，0.1.45 (46)。macOS/iOS 共用 Rust 代理和 SSH 核心。

## 使用

左侧“连接代理”分为**默认代理**和**命名代理**。默认代理可选择直接连接、HTTP CONNECT 或 SOCKS5，填写代理域名/IP、端口及可选用户名/密码；地址不包含协议、端口或路径，IPv6 使用裸地址，国际化域名需要填写 ASCII/Punycode 形式。命名代理可保存多个，各自有名称、协议、端点与可选凭证。

主机编辑器新增“连接代理（仅第一跳）”：

- **继承默认代理**：使用默认代理设置（旧版全局设置直接成为默认，无需迁移）。
- **直连（不使用代理）**：即使默认代理已配置也明确直连。
- **指定命名代理**：只使用该命名代理。此设备缺少对应配置时拒绝连接，不会回退默认或直连。

代理只用于直连第一跳；多级跳板的后续跳经上一跳通道访问目标，不再叠加代理。保存不连接网络，也不改变已有会话；GitHub 同步不使用此设置。

同一地址、端口、协议和用户名可留空保留加密保存的密码。修改任一项后必须重新输入，防止把旧凭证发送到新代理。关闭认证并保存会清除凭证；选择“直接连接”保存会清除默认代理。取消不保存。读取失败时可以重试或显式清除代理恢复直连。

## 分层连通测试

连接代理窗口和命名代理编辑器提供“测试”：可填写目标主机/端口，也可留空只测代理 TCP。结果分三段显示：

1. **代理 TCP 可达**：仅表示能连上代理地址和端口。
2. **代理认证通过**：HTTP 407 或 SOCKS5 用户名/密码失败会明确显示失败；服务器返回其他拒绝状态视为认证已通过。
3. **目标可达（TCP）**：代理成功连接到目标端口，不包含 SSH 握手、主机指纹或 SSH 认证。

测试超时为 TCP 8 秒、协议 10 秒；只使用代理自身的网络路径，不发送 SSH 凭证。可以测试默认代理、指定命名代理、未保存草稿，或在“测试全部”中按顺序测试所有命名代理。默认代理已保存但表单有未保存修改时，测试仍使用已保存配置。

## 连接与安全边界

- HTTP 支持 HTTP/1.0/1.1 CONNECT 和可选 Basic 认证；SOCKS5 支持 TCP CONNECT、无认证或用户名/密码认证。SOCKS5 只声明所选认证方法，不接受静默降级。
- HTTP 将目标 authority 交给代理，SOCKS5 将目标域名/IP 编码后交给代理；仅代理地址在本机解析。代理失败不会尝试直接连接目标。
- TCP、代理协商和 SSH 初始握手各有 20 秒上限，失败释放套接字。0.1.44 起探测接受 operation id，可通过 `cancel_probe` 在握手阶段即时取消；连接 id 返回后改用断开对应连接或整链根节点。多级跳板只对第一跳应用本机代理。
- 代理隧道建立后，在**同一传输**读取目标服务器指纹，再进入已有指纹确认/变化阻断和认证流程。代理密码是发给代理的凭证，与经过指纹校验后才发送的 SSH 凭证不同。
- HTTP 响应头总量限制为 16 KiB（包括临时响应）；精确读取头部终止符，保留同一数据包中的 SSH banner。错误只呈现状态码和本地提示，不回显代理返回的任意正文。
- 代理密码存入 SQLCipher：默认代理使用 `connection_proxy_v1`，命名代理使用 `connection_proxies_v1`，主机绑定使用 `host_proxy_bindings_v1`。读取接口只返回“密码已保存”标记，不回填密码。命名代理和主机绑定都只在本机保存，不进入 GitHub 同步快照，也不由当前备份恢复界面导入；恢复后需重新设置。删除仍被主机使用的命名代理会被阻止；主机删除或同步变化后失效绑定会在后续代理操作中清理。
- 配置了代理（默认或指定命名代理）时，代理失败只报错，不回退直连；显式“直连”是唯一绕过方式。指定命名代理在本机缺失时同样拒绝连接。
- HTTP Basic 和 SOCKS5 用户名/密码认证本身不加密客户端到代理这一段。使用可信网络或本机代理；本次没有 HTTPS 代理、Digest/NTLM/GSSAPI、SOCKS4、UDP、系统代理自动发现和 ProxyCommand。参照 [HTTP CONNECT](https://www.rfc-editor.org/rfc/rfc9110.html#name-connect)、[SOCKS5](https://www.rfc-editor.org/info/rfc1928/)、[SOCKS5 密码认证](https://www.rfc-editor.org/info/rfc1929/)。
