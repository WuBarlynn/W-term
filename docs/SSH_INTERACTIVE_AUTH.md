# SSH 交互式认证与 MFA

更新：2026-10-28，0.1.45 (46)。macOS/iOS 使用同一个 Rust 认证流程。

## 使用

- 已保存密码或私钥的主机仍双击连接。服务器在第一步之后要求 keyboard-interactive（例如一次性验证码）时，自动弹出“服务器交互式认证”。私钥解密口令仍在原身份中管理，与服务器验证码不同。
- 问题窗口显示连接目标及服务器提供的标题/说明，每个问题按服务器的 echo 标记决定是否遮蔽。服务器未提供字段的轮次需要显式点击“继续”，不自动确认。
- 多轮认证逐次显示。点击“取消连接”、连接取消、超时或认证结束会清除输入并关闭当前问题窗口。错误验证码由服务器决定是否继续出题或拒绝；客户端不会重新提交旧答案。
- **持久纯交互式身份：**在“身份与密钥”中新建或编辑身份，选择“仅交互式”，只填写名称和用户名。保存后不包含密码、私钥或口令；每次连接（包括跳板）由服务器在打开终端前询问，重连会重新询问。也可继续用“新建连接”留空密码的临时方式。
- 交互式身份可用于跳板路线中的跳板或目标；跳板只认证，不打开终端。MFA 回答不落库、不同步、不自动重放。

## 安全与资源边界

先在同一 SSH 传输上验证/确认服务器指纹，再发送任何认证数据。指纹变化继续阻断；交互式认证不重新连接，也不跳过既有指纹审批。

密码/公钥第一步未完成且服务器列出 keyboard-interactive 时才进入问答，支持 partial-success 后继续，以及服务器要求的密码/验证码组合提示。认证回答只在此次连接内传递，不写入 SQLCipher、身份、主机或同步快照，也不自动填充保存的密码。

每轮问题和回答绑定连接 ID 与随机问题 ID；拒绝跨连接、旧轮次、重复提交、回答数量不符或单项超过 16 KiB 的请求。每轮最多 16 个问题，标题/单个标签最多 4 KiB，说明最多 16 KiB，最多 8 轮。界面显示服务器文本，不把它当成本地命令或外部链接执行。

网络认证步骤最长 20 秒，用户每轮回答最长 120 秒，整体认证最多 300 秒；认证后的终端启动最长 30 秒。失败或取消清除等待问题、认证登记并断开连接。只有完整认证及 PTY/shell 建立成功后才注册可用终端/SFTP/转发会话。应用已有的后台断连策略继续生效。

初始凭证发送后尽早清空本层持有的副本，答案提交后清空可控容器；Dart 不可变字符串、FFI 和 SSH 库内部可能存在短期副本，不承诺整个进程内存即时物理清零。

## 验证

- Rust 本地协议服务器：密码及公钥 partial-success 后追加挑战、纯交互式、多提示及 echo、零输入后续轮次、错误答案、取消、错误指纹阻断、成功终端输出。
- 核心单元：问题 ID/连接绑定、回答数量校验、重复提交拒绝、等待超时清理和超限标题拒绝。
- Flutter：遮蔽/回显、多字段、零输入确认、取消、认证结束自动关闭、手机键盘布局、回答提交后清理及不重放。
- 独立 AsyncSSH fixture + 实际 Dart/Rust 库：两轮认证后访问同传输 SFTP，过期回答拒绝；保存的“仅交互式”身份在保险库锁定/重开后再次认证并重新询问。旧 SSH/SFTP/转发回归共用 `scripts/test-core.sh`。

执行命令：

```bash
source scripts/env.sh
export RUSTUP_TOOLCHAIN=1.98.1-aarch64-apple-darwin
WTERM_TEST_FORWARD_BRIDGE=1 bash scripts/test-core.sh
```

仅使用临时 loopback 服务和合成凭证，未连接用户服务器。真实 OpenSSH/PAM/TOTP 服务、签名设备上的验证码输入/后台取消仍需验收。FIDO/硬件私钥、SSH Agent 及完整认证策略配置不在本次范围。仅交互式身份在同步快照中必须不含任何凭证；旧版客户端遇到该身份类型会拒绝写入，需先升级。
