# 仅本机同步范围

更新：2026-10-08，0.1.40 (41)。入口：侧栏“GitHub 同步” → “管理仅本机范围”。先创建或接入同步空间；无需先发布，也无需先核验新空间的恢复码。

## 使用方式

1. 搜索主机、身份或命令片段，勾选需要仅本机保存的记录。
2. 检查“直接选择”与“由关联主机或身份一起排除”的区别。共用身份的主机会一起排除，计数包含关联项。
3. 勾选确认范围和关联影响，然后保存。保存只修改本机规则，不访问 GitHub、不发布、不删除本机记录；后续普通同步使用新范围。
4. 取消窗口不会保存选择。搜索只过滤显示，隐藏项的选择保留。取消直接选择时，会重新计算关联影响；记录若仍被另一条规则关联，继续排除。

规则在 SQLCipher 中持久化，仅作用于本机，规则本身不加入同步快照。恢复默认参与同步时，下一次手动同步仍需合并，冲突继续保留双方。已删除记录的显式规则保留显示，可手动移除，不会因此恢复已删除记录。

## 关联与边界

- 主机 → 保存的身份 → 共用该身份的其他主机，沿关联关系共同排除；也检查本机同步检查点中的旧关联，避免更换身份后意外泄露旧凭证。
- 片段单独排除。文件夹树仍参与同步，不提供单独排除文件夹的开关。
- 已确认同步的数据不能直接改为仅本机。列表标记已同步项并禁用直接勾选；若新选择通过关联涉及已同步项，预览显示原因并禁止保存。远端撤回尚未实现；仅本机规则不能抹除仓库历史或其他设备副本。
- 待处理发布、轮换、发件箱和冲突审阅会阻断保存；不会为改变范围而丢弃待处理数据。
- 若其他设备尚有本机未读取的同 ID 数据，下一次普通同步仍执行核心隐私检查，可能停止并要求处理；本地预览不能证明远端从未保存过该记录。

## 实现和验证

沿用 `state::Policy` 的依赖闭包及同步快照排除规则，不新增同步协议。预览只返回受限摘要、分类、编号、选择/关联/已同步标志，不向 Flutter 返回密码、私钥、私钥口令或片段正文。

预览版本绑定当前同步状态、业务快照和完整拟选规则。保存使用同一个 SQLCipher 写事务重新计算预览，核对版本、待处理状态及基线限制，再写入规则和操作版本。主机重命名、关联变化、凭证编辑或其他同步操作后，旧预览无法保存；数据库失败全部回滚。

验证记录见 [STATUS.md](STATUS.md)。真实 GitHub 与签名双设备验收仍待完成；自动化不等于真机验证。
