# 标签与分屏工作区（P1.5-A/B）

更新：2026-10-30，0.1.49 (50)。macOS/iOS 共用终端会话服务与布局模型；弹窗窗口、广播、重连/布局持久化仍属后续批次。

## 设计

- **会话与视图分离**：`TerminalSession` 持有 xterm 模型、SSH 输出订阅、ACK、输入写队列、resize 与结束状态；`TerminalPane` 只是可移动视图。切换标签、重排布局或移动窗格不会重新连接、不会丢失滚屏缓冲。
- **标签**：每个标签有自己的窗格树。默认一次连接创建一个单窗格标签；标签可拖动排序、双击/长按重命名、关闭。关闭标签会断开其中所有会话。
- **分屏**：窗格菜单提供水平/垂直分屏；选择一个已打开的其他会话放入新窗格。支持嵌套（在已有分屏中继续分屏）、拖动分隔条调整比例、点击窗格切换输入焦点，以及“拆回标签”。
- **拖拽合并**：标签栏的分屏手柄可拖到任意窗格的上/下/左/右边缘，显示落点高亮；松开后把整个标签树合并到该位置，源标签移除。
- **文件/转发**：标签工具栏对当前活动窗格提供 SFTP 和端口转发入口；切换活动窗格后使用对应会话。

## 操作

1. 连接多台主机后，标签栏横向排列，可拖动标签前的排序手柄重排。
2. 在任一终端窗格右上角菜单选择“水平分屏/垂直分屏”→ 选择另一已连接/已断开会话；新窗格获得焦点。
3. 拖动窗格间分隔条调整比例；点击窗格切换焦点（顶部主色细线标识活动窗格）。
4. 在窗格菜单中选择“拆回标签”把该会话移回独立标签；选择“关闭窗格”只关闭该窗格（确认后断开该会话）。
5. 拖动标签栏的“拖到窗格边缘分屏”手柄到窗格四边，预览高亮后松开即可合并整个标签。
6. 双击或长按标签标题重命名；留空恢复主机名。

## 状态、资源与边界

- SSH 会话、终端缓冲和输出由 `TerminalSession` 持有；视图销毁/移动不会触发断链。关闭标签/窗格或工作区销毁才会关闭会话并释放转发、SFTP 与远端资源。
- 同一会话只允许出现在一个窗格；分屏选择会从原标签移动会话，而不是复制终端。复制会话/继承 cwd 尚未实现。
- 每个标签的分屏树保存在内存；重启/重连后的布局恢复、描述性布局文件属于 P1.5-F，尚未实现。
- 选中文本、滚动位置和输入焦点是视图状态；移动窗格时终端缓冲保留，但视图级选择/滚动位置可能重置。弹窗独立窗口、保活迁移和广播输入属于 P1.5-C/D。
- iOS 进入后台仍按现有策略断开 SSH；恢复后标签保留但显示已断开，不会自动重连。
- 小窗格工具栏自动折叠到菜单，避免分屏后按钮溢出；移动端辅助键条仍保留。

## 整标签拖动与右键菜单（0.1.49）

- 标签标题区域整体可拖动，左侧排序手柄仍只负责调整标签顺序。拖动经过终端窗格时按最近边缘高亮上/下/左/右落点，落点可以在窗格任意位置，不再要求命中窄边缘条。
- 拖到另一个标签项上可直接把整个标签树合并到该标签右侧；拖到另一个已显示窗格的边缘则按该边缘合并。
- 把当前标签拖到自己的窗格边缘时，因为标签不能与自身合并，改为弹出“另一个已打开会话”选择框，将所选会话移入该边缘分屏。
- 右键标签（触屏长按）打开菜单：重命名标签、分屏子菜单（左右双分屏/上下双分屏/四宫格分屏）、拆回当前窗格、关闭当前窗格、关闭标签、关闭其他标签、新建连接。
- 四宫格会补足当前标签到 4 个窗格：从其他标签选择缺少的会话，然后按 2×2 重新排列；会话只移动视图，不重连、不复制。关闭其他标签会确认将断开的会话数。
- 真实鼠标/触控拖动、菜单弹出位置与四宫格选择仍需要签名设备人工复核；自动化覆盖最近边缘计算、窗格顺序与四宫格树结构。

## 侧栏、文件面板与标签关闭（0.1.48）

- 左侧主机栏可拖动右侧分隔条调整宽度（200–480）；顶部箭头收起为 48px 窄栏，窄栏保留展开、新建连接、设置与锁定按钮。左下角设置项收进“设置与工具”菜单，避免占用主机列表高度。
- 右侧 SFTP 面板可拖动左侧分隔条调整宽度（240–560）；收起后保留显示文件、上传、刷新文件列表三个按钮，终端获得剩余空间。窄屏仍以整页切换终端/文件。
- 关闭标签只断开该标签自己的会话：先移除视图和标签状态，再逐会话关闭 SSH。确认框列出将被断开的 `用户名@主机`；关闭一个标签不会重建或断连其他标签。
- 这些面板尺寸/折叠状态目前只保留在当前进程内，不写入布局文件（P1.5-F）。
